Sao Lưu & Khôi Phục Dữ Liệu

Dữ liệu được lưu an toàn trực tiếp trên trình duyệt của máy bạn. Bạn có thể xuất file sao lưu để chuyển sang máy tính khác hoặc lưu trữ định kỳ.

Xuất file dữ liệu (Backup)

Tải toàn bộ danh sách lớp, học viên, lịch sử buổi học và học phí về máy dạng file .json

Nhập lại file dữ liệu (Restore)

Chọn file .json đã lưu trước đó để nạp lại dữ liệu.

Khôi phục dữ liệu mẫu Tiếng Trung ban đầu

Nạp lại bộ dữ liệu lớp học tiếng Trung HSK mẫu chuẩn để dùng thử lại từ đầu.

☁️ Đồng Bộ Dữ Liệu Đám Mây (Google Firebase)

Lưu trữ dữ liệu online lâu dài, không bao giờ bị tạm dừng/hết hạn

💡 Hướng dẫn 3 bước kết nối Google Firebase (Miễn phí vĩnh viễn):
1. Truy cập console.firebase.google.com, đăng nhập Google và bấm Tạo dự án (Create a project).
2. Vào mục Build → Firestore Database → bấm Create database (ở tab Rules dán đoạn Rules bên dưới và bấm Publish).
3. Vào cài đặt dự án (Project settings) hoặc bấm biểu tượng Web </> để lấy đoạn mã firebaseConfig rồi dán vào ô bên dưới. 
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /zhongwen_app_data/{document} {
      allow read, write: if true;
    }
  }
}
